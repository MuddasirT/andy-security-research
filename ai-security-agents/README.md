# AI Security Agents

This workspace contains the AI-assisted security research programme and the Andy multi-agent orchestration foundation.

- [Andy Core](andy-core/README.md): local-first orchestrator, specialist registry, SQLite task ledger, and CLI.
- [Architecture](andy-core/ARCHITECTURE.md): command hierarchy and planned system design.
- [Safety policy](andy-core/SAFETY.md): permission boundaries and approval requirements.
- [Build roadmap](andy-core/ROADMAP.md): staged implementation and release gates.
- [Operational status](andy-core/STATUS.md): what is implemented versus actually deployed.

Andy Core is a software foundation, not an always-on hosted service. Run it locally and verify the checks before treating any worker as operational.
